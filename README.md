## 🇬🇧 English

> **Course:** YZM301 · Week 2 assignment

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> About the Project
**SoruX** is a modern AI search engine inspired by Perplexity AI, localised for Türkiye, KVKK (Turkish GDPR) compliant and prioritising Turkish-language sources. Instead of just a list of web links, it gives users instant answers compiled and analysed from trusted local sources (TRT, TÜBİTAK, BIST and more). The design takes inspiration from Lumosity/Lunosity: a bright interface, bold typography and warm cream/beige tones.

The project aims to build an innovative (disruptive) product suited to local needs in Agentic AI Search, the "technological earthquake" of 2026 (Assignment 3).

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Key Features
* ⚡ **Instant AI answers:** Detailed, sourced and verified answers to your questions in milliseconds.
* 🇹🇷 **Turkish first:** Dedicated access to local sources such as TRT, Milliyet and TÜBİTAK.
* 📚 **Cited answers:** Clickable reference sources under every answer.
* 🤖 **Agentic search:** A smart agent system that solves multi-step tasks automatically.
* 🔒 **KVKK compliant:** Local infrastructure that keeps data in Türkiye.
* 🎨 **Premium UI/UX:** Lunosity-inspired cream background, bold typography and clean "floating card" design.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Magnifying%20Glass%20Tilted%20Left.png" width="26" align="center"> Screens

| Screen | Description |
| :--- | :--- |
| 🏠 **Home** | Focused search bar, trending topics and SoruX's core value propositions. |
| 🧭 **Discover** | Trending searches and featured collections in technology, science, finance and more. |
| 👤 **Profile** | User statistics, recent searches, achievements and favourite topics. |
| ✨ **Results** | AI-generated answers with a typing effect and related source links. |

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Laptop.png" width="26" align="center"> Installation and Running

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The server runs at `http://localhost:5173/`.

## 🇹🇷 Türkçe

> **Ders:** YZM301 · 2. hafta ödevi

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> Proje Hakkında
**SoruX**, Perplexity AI'dan ilham alınarak geliştirilmiş, Türkiye için yerelleştirilmiş, KVKK uyumlu ve Türkçe kaynakları önceliklendiren modern bir AI arama motorudur. Kullanıcılarına sadece web linkleri değil, güvenilir yerel kaynaklardan (TRT, TÜBİTAK, BIST vb.) derlenmiş ve analiz edilmiş anlık yanıtlar sunar. Tasarımında Lumosity/Lunosity'den ilham alınmış; aydınlık, kalın tipografi ve sıcak krem/bej tonlarıyla modern bir web arayüzü deneyimi sağlanmıştır.

Bu proje, 2026'nın "teknolojik depremi" olan Agentic AI Search alanında, yerel ihtiyaçlara uygun yenilikçi (disruptive) bir ürün ortaya koymayı amaçlamaktadır (Ödev 3).

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Temel Özellikler
* ⚡ **Anlık AI Yanıtı:** Sorularınıza milisaniyeler içinde kaynaklı, detaylı ve doğrulanmış cevaplar.
* 🇹🇷 **Türkçe Öncelikli:** TRT, Milliyet, TÜBİTAK gibi yerel kaynaklara özel erişim.
* 📚 **Kaynaklı Cevaplar:** Her yanıtın altında tıklanabilir referans kaynaklar.
* 🤖 **Agentic Arama:** Çok adımlı görevleri otomatik çözen akıllı ajan sistemi.
* 🔒 **KVKK Uyumlu:** Verilerin Türkiye'de kalmasını sağlayan yerel altyapı.
* 🎨 **Premium UI/UX:** Lunosity ilhamlı, krem arka plan, kalın tipografi ve temiz "floating card" tasarımı.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Magnifying%20Glass%20Tilted%20Left.png" width="26" align="center"> Kullanım ve Ekranlar
